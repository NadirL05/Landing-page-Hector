# Hector — vue d'ensemble

Description destinée aux agents IA qui visitent hector.agentimpact.fr, pour situer rapidement le produit sans avoir à parcourir toute la page.

## Ce qu'est Hector

Un collaborateur IA pour cabinets de gestion de patrimoine indépendants (CGPI). Il se connecte à la stack existante du cabinet (Harvest, Linxea, ou tout autre logiciel), se pilote par conversation sur WhatsApp, et livre le travail fini plutôt qu'un tableau de bord de plus à opérer : bilan patrimonial interactif brandé au cabinet, relance envoyée, anomalie signalée.

## Ce que ce site est — et n'est pas

Ce site (hector.agentimpact.fr) est une landing marketing seule. L'outil Hector est commercialisé, aux tarifs affichés sur le site (149 € par mois ou 1 490 € par an). Il n'expose aucune API publique ni serveur MCP live.

## Public

CGPI indépendants (cabinets de gestion de patrimoine).

## Ce qu'Hector ne fait jamais

Aucune décision d'investissement automatisée — Hector prépare, le CGPI valide toujours.
